# Simple Blog Website 📝

A simple blog website where users can create blog posts with images and interact with other users by commenting on their posts.

## 🚀 Features

- 📰 Create and publish blog posts
- 🖼️ Upload images for blog posts
- 💬 Comment on blog posts by other users
- 📱 Responsive and user-friendly UI
- 🔐 User-based interactions (posting & commenting)
